# Aiden Wang Portfolio

Professional portfolio website built with React, TypeScript, Three.js, and Framer Motion.

**Live:** Deployed on Replit

## Features
- Hero, About, PlantAI Health, Robotics, Games, Projects, Contact sections
- Dedicated PlantAI Health page with live preview and version history
- Playable Snake Game (3 modes) and 3D Solar System Explorer
- Dark/light mode toggle
- Responsive design with Framer Motion animations

## Tech Stack
- React + TypeScript
- Tailwind CSS + shadcn/ui
- Three.js (React Three Fiber)
- Framer Motion
- Express backend
- Vite build tool
